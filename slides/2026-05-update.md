## Scope Ceiling

- Gets introduced via ModuleSource
- A: `scopeHook` on the same `handler` as `importHook`
- B: object passed to the constructor

> option A leaves more flexibility to figure out when to call the hook. 
---

[16.2.1.7.3.1 InitializeEnvironment ( )](https://tc39.es/ecma262/multipage/ecmascript-language-scripts-and-modules.html#sec-source-text-module-record-initialize-environment)

```perl
3. Let realm be module.[[Realm]].
4. Assert: realm is not undefined.
+ if module.[[ScopeCeiling]] is not EMPTY, then
+     Let outer be NewObjectEnvironment(module.[[ScopeCeiling]], false, null)
+   Else
+     Let outer be realm.[[GlobalEnv]]
5. Let env be NewModuleEnvironment(outer).
6. Set module.[[Environment]] to env.
```
> note: NewObjectEnvironment could be called earlier
